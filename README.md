# Deceitful Duck
A work in progress.
Deceitful Duck is a game where you are a duck trying to steal from geese. You need to sneak through hallways, avoid geese, and collect your hard-earned loot.
I made this project for Hack Club Shiba and Athena award. (See below)

[![Athena Award Badge](https://img.shields.io/endpoint?url=https%3A%2F%2Faward.athena.hackclub.com%2Fapi%2Fbadge)](https://award.athena.hackclub.com?utm_source=readme)

I made this game with Godot, some pixel art, and a healthy dose of procrastination :D
It was hard to get the top-down view to look right, and it still looks a bit off. I also spent a lot of time trying to get the geese to not stick to or walk through the walls, but that also hasn't worked yet.
I did at least learn how to randomly generate levels though, and that is currently the main feature of the game!
